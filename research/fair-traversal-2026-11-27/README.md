# Fair Traversal Conjecture: partial results and exact certificates

**Research checkpoint, 27 November 2026. The full conjecture remains unresolved.**

This directory records work on [Left to Solve problem `gillibert-fair-traversal`](https://lefttosolve.com/p/gillibert-fair-traversal), rated 82/100 when selected. The task is to prove or disprove that every finite connected vertex-transitive simple graph with at least two vertices admits a nonempty finite multiset of Hamiltonian paths in which every edge occurs the same positive number of times.

The source is [Luc Gillibert's Fair Traversal manuscript](https://github.com/Gillibert/ConjecturesGillibert/blob/main/fair_traversal_conjecture.tex). This checkpoint does not claim a solution of the site's unrestricted theorem, and makes no claim of priority for the partial results.

## Main mathematical result

The complete argument in [structural-results.md](structural-results.md), Section 7, establishes:

> Every connected Cayley graph of a finite abelian group has a fair traversal. More generally, the same holds if every subgroup generated by a subset of the selected inverse-pair generators is normal in the whole group. In particular it holds for every finite Dedekind group.

For a group of order `n`, partition the connection set into inverse pairs, of sizes `d_i` equal to one or two, and let `d = sum d_i`. The required expected number of type-`i` edges is `(n-1)d_i/d`.

For every ordering of the generator pairs, successive subgroup paths can be joined through cyclic quotient cosets. If `H_j` is the subgroup generated by the first `j` pairs, the resulting Hamilton path uses

`n/|H_(j-1)| - n/|H_j|`

edges of the newly introduced type. The target count satisfies every prefix bound. Sorting an arbitrary real edge-type weighting and summing by parts proves that some constructed path has at least the target weighted value. Finite convex separation then places the target in the convex hull of the constructed count vectors. Rational coefficients and averaging over group translations produce the required finite multiset.

The proof was checked independently twice. A constructive implementation is provided in [abelian_certificate.py](abelian_certificate.py); its seven demonstration certificates are in [abelian_examples.json](abelian_examples.json). Verification expands every group translation and checks integer coverage of every edge. Across these examples, all 302 generator orderings were also checked against independently recomputed subgroup sizes.

## Other proved results

The same note gives full ordinary mathematical proofs of:

- An exact edge-orbit convex-hull criterion, using any explicitly supplied vertex-transitive automorphism subgroup.
- A rational/integer separating-weight criterion for a counterexample.
- The equivalence between fairness and equality in the density lower bound for fractional linear arboricity.
- Closure under Cartesian products of regular fair graphs, with an explicit rational mixture of two path constructions.
- A concrete obstruction to extending the subgroup proof directly: the 30-vertex Petersen triangle expansion has an external matching of graphic rank 15, but no Hamilton path uses more than 11 matching edges. The graph is nevertheless fair, with the required mean 29/3 external edges. Thus the stronger prefix-saturation property used by the construction is false for general vertex-transitive graphs.

These are written proofs, not Lean formalizations. The exact finite computations below are also not Lean kernel proofs. The full site target has not been submitted as solved.

## Finite search and verification

[certificates.jsonl.gz](certificates.jsonl.gz) contains **4,780 positive finite-instance certificates**, each with the complete graph, transitive automorphism generators, explicit Hamiltonian paths, and exact rational weights.

|---|---:|---:|

| Dihedral Cayley graphs | 1,938 | 6–40 |
| Symmetric-group Cayley graphs | 273 | 6–24 |
| Generalized Petersen graphs | 17 | 10–64 |
| Generalized Petersen complements | 5 | 16–32 |

| Cycle/square truncations | 10 | 20–120 |
| Sparse coset orbital unions | 293 | 8–30 |
| Cubic vertex-transitive census | 264 | 6–64 |
| **Total** | **4,780** | **4–120** |

These are input instances, **not a count of pairwise nonisomorphic graphs**. Some different families or generating sets yield isomorphic graphs. No claim is made that all vertex-transitive graphs up to any order were tested. The census subcollection specifically covers the 264 non-edge-transitive cubic catalogue entries through 64 vertices, including its 17 non-Cayley entries and 102 entries with three edge orbits.

The Cayley search used deterministic generator-set selections; the exact selection rules and random seeds appear in [cayley_search.py](cayley_search.py). The coset search covered 18 actions of `S4`, `S5`, and `A5` and selected connected orbital unions of degree 3–6 with at least two edge orbits; the regular `S4` action was sampled. The complete graphs and symmetry witnesses are in the certificate file, so verification does not depend on reproducing any search or group-classification calculation.

Two additional 70-vertex Johnson cases timed out without a usable path from the optimization oracle. They are recorded separately in [unresolved.jsonl](unresolved.jsonl), excluded from the positive count, and are not evidence against the conjecture.

The MILP/LP code in [search.py](search.py) was used only to discover candidate paths and weights. The Hamilton-path oracle uses a dummy vertex, degree-two constraints, and flow connectivity. Positive results were then converted to rational witnesses. A separate exact verifier recomputes the relevant properties from the supplied witnesses. A non-vertex-transitive cubic graph with a bridge was used as a negative control; the optimizer correctly detected its incompatible uniform target.

### Run the independent verifier

This requires only the Python standard library:

```sh
python verify_certificates.py certificates.jsonl.gz
python abelian_certificate.py verify abelian_examples.json
```

Do not use Python `-O`; the programs explicitly reject it because their exact checks use assertions.

The verifier checks that every generator is a graph automorphism, that the generated group is transitive on vertices, and that the stated paths visit all vertices exactly once along genuine edges. It recomputes the edge orbits and checks the exact rational identity

`expected path edges in orbit O = (n-1)|O|/|E|`.

Averaging over the finite generated group therefore gives every edge marginal `(n-1)/|E|`. Denominator clearing yields the finite multiset. It is unnecessary to identify the graph's full automorphism group.

The final audit is recorded in [verification-summary.json](verification-summary.json). The compressed certificate file has SHA-256:

`0f40ddf903071d165bde1c7ccf9a38d9e4a48f475657042c621961ff3a7fd52a`

Only construction/search requires third-party packages:

## Remaining problem

No argument here proves that every connected vertex-transitive graph has a Hamilton path, or that its uniform edge-incidence vector lies in the convex hull of Hamilton paths. The infinite-class theorem, closure results, finite certificates, and explicit limits of the proof method are the completed contribution of this checkpoint.
